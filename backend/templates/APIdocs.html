API Documentation

GET /api/users

Returns a list of all users.

Response

    [
        {
            "id": 1,
            "name": "John Doe",
            "email": "john@example.com"
        },
        {
            "id": 2,
            "name": "Jane Doe",
            "email": "jane@example.com"
        }
    ]

GET /api/users/:id

Returns the user with the specified ID.

Response

    {
        "id": 1,
        "name": "John Doe",
        "email": "john@example.com"
    }

POST /api/users

Creates a new user. The request body should include the user's name and email.

Request

    {
        "name": "John Doe",
        "email": "john@example.com"
    }

Response

    {
        "id": 1,
        "name": "John Doe",
        "email": "john@example.com"
    }
